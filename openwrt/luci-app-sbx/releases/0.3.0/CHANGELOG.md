当前打包修订：`0.3.0-r20`

- `0.3.0-r20` 版本检测改为轻量 tags API，直连优先、失败才回退代理；OpenWrt 回退只接受 `openwrt-v*`，避免把 Linux 版本误判为 OpenWrt 版本；sing-box 最新版同样改用 tags，检测耗时从约 22 秒降到 1 秒左右。

- `0.3.0-r19` 将 TProxy 的 nftables 表改为单事务原子替换，避免首次安装或重启时出现规则空窗；失败时保留旧表继续生效。

- `0.3.0-r18` 修复更新事务重复下载配置导致页面长时间卡住；事务重启 sing-box 时跳过第二次同步。

- `0.3.0-r17` 修复“更新当前配置”优先读取过期 `config_profile` 导致实际运行在 TUN/TProxy 时误判为 `proxy-only` 的问题；现在以当前 `mode` 为准，并保留旧配置兼容回退。

- `0.3.0-r16` 在 LuCI 配置页面增加“更新当前配置”，根据当前 TUN/TProxy 模式下载对应配置，校验、备份、重启并在失败时自动回滚。

## 本版本

- `0.3.0-r15` 增加日志级别选择并默认使用 `info`；日志级别会在远程配置下载、模式切换和重启时自动重新应用，避免被订阅配置中的 `warn` 覆盖。

- `0.3.0-r14` 将日志刷新切换为 LuCI 原生轮询：日志选项卡打开时每 3 秒刷新，提供立即刷新、最后刷新时间及自动滚动开关；同时启用 sing-box 的 procd 标准输出和错误日志采集。

## 已知事项

- 本插件定位为旁路由，不修改上游主路由器配置。
- DNS 明文上游风险由健康检查提示，但不会自动修改用户的 mosdns、AdGuard Home 或 RouterOS 配置。
- ImmortalWrt 25.12 系列优先使用 APK；传统 OpenWrt/ImmortalWrt 环境可使用 IPK。
